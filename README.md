# OTC · Comunità connesse

Demo pubblica del sito OTC su GitHub Pages.

- Atmosfera sonora automatica e interruttore audio in alto.
- Frasi latine con traduzione e parole evidenziate sui tempi della voce.
- Cinque esempi Menestrello con voce Elsa: rifiuti, Comune, biblioteca, mercato e protezione civile.
- Configuratore e diffusione dimostrativi: nessun comando viene inviato agli impianti.

Questa versione è statica e utilizza esclusivamente audio già pronti. Non comprende la sintesi dei testi personalizzati.

La pubblicazione avviene dal ramo `main`, cartella principale, tramite GitHub Pages.
